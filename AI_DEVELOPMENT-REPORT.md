# AI-Assisted Development Report

## 1. AI Tools Used

- ChatGPT: Used for development guidance, code explanations, debugging assistance, and UI styling suggestions.
- Google Gemini API: Used by the application to interpret natural-language questions and generate SQL queries.

## 2. How AI Was Used

AI assistance was used to understand implementation approaches, improve the application, troubleshoot errors, and refine the user interface. The generated code was reviewed and tested during development.

## 3. Problems Encountered

- Gemini model availability and API service errors.
- Streamlit theme and CSS conflicts while styling the file uploader.
- Challenges in validating generated SQL and handling invalid inputs.

## 4. Debugging Approach

Errors were investigated using terminal output, application behavior, and browser Developer Tools. Changes were tested incrementally, and the Streamlit theme configuration was adjusted to resolve the appearance issue.

## 5. Known Limitations

Document the question types that work, unsupported questions, any missing test coverage, and any remaining issues observed during testing.

## 6. Improvements With One More Day

- Expand automated test coverage.
- Improve handling of ambiguous questions and SQL-generation failures.
- Add more validation and clearer error messages.
- Improve the architecture documentation and application logging.
